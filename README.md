# Collab Study Room

A real-time collaborative study platform that helps students learn together through shared study rooms, group communication, and synchronized learning sessions.

## 🚀 Overview

Collab Study Room is a web-based platform designed to make online studying more interactive and productive. Users can create or join study rooms, collaborate with peers, communicate in real time, and stay focused through a shared learning environment.

The project was built to address the challenges of remote studying by providing a virtual space where students can study together regardless of location.

## ✨ Features

### 👥 Study Rooms

* Create private or public study rooms
* Join existing rooms using room codes
* View active participants in real time

### 💬 Real-Time Communication

* Instant group chat within study rooms
* Live message updates without page refresh
* Participant activity tracking

### 📚 Collaborative Learning

* Shared study environment
* Real-time synchronization between users
* Interactive group sessions

### 🔐 User Authentication

* Secure user registration and login
* Protected routes and personalized dashboards
* Session management

### 🎯 User-Friendly Interface

* Responsive design for desktop and mobile devices
* Clean and intuitive user experience
* Modern React-based frontend

## 🏗️ System Architecture

1. Users authenticate using Firebase Authentication.
2. Study room data is stored in Firestore.
3. Real-time listeners update room information instantly across connected users.
4. Messages and participant activities are synchronized through Firebase services.
5. React manages UI rendering and application state.

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/collab-study-room.git
cd collab-study-room
```

### Install Dependencies

```bash
npm install
```

### Configure Firebase

Create a `.env` file in the root directory:

```env
VITE_FIREBASE_API_KEY=your_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_storage_bucket
VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
VITE_FIREBASE_APP_ID=your_app_id
```

### Run Locally

```bash
npm run dev
```
